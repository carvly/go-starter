# 当前项目模块与链路

本文件归业务项目所有；starter 通用架构见 `docs/ARCHITECTURE.md`。

## 模块清单

- `user`：前台用户、登录、会话、注销和前台鉴权中间件。
- `staff`：后台员工、角色权限、操作日志和后台鉴权。

## 链路

通用的请求与任务链路见 `docs/ARCHITECTURE.md`"一个请求和一个事件怎么走"。项目特有的部分：
登录、绑定、解绑和注销由 user 处理，注销在同一事务里发布 `user_deleted`，由 user 自己的 worker 调用各模块
登记的清理器；后台员工、角色权限和操作日志由 staff 处理。
