# 当前项目模块与链路

本文件归业务项目所有；starter 通用架构见 `docs/ARCHITECTURE.md`。

## 模块清单

- `auth`：前台用户、登录、会话、注销和前台鉴权中间件。
- `staff`：后台员工、角色权限、操作日志和后台鉴权。

## 请求与任务链路

前台请求经过 `httpserver` 的全局中间件链、按 tag 生成的模块路由和模块 Service。
登录、绑定、解绑和注销由 auth 处理；后台员工、角色权限和操作日志由 staff 处理。
需要异步处理时，业务写入与 river 入队在同一个事务提交，worker 按事件里的 request_id
重建日志上下文。
